# Audio-player

Audio player in C.

## Feature

- [x] Play local file.
- [ ] Play remote file.

- [x] Play MP3 file.
- [ ] Play WAV file.
- [ ] Play FLAC file.

## Build

### Compile

```bash
make
```

### Run

```bash
./audio_player <path-to-audio-file>
```

### Output

```bash
====================
--- Audio Player ---
====================

  Playing : music/Finneas-Little_window_live.mp3.

Infos :
- BitRate : 44100
- Channels : Stereo

```
